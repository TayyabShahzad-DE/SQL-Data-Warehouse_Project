
# 🏗️ SQL Data Warehouse Project

An end-to-end data warehousing project built using SQL Server. This project focuses on building a data warehouse, integrating data from multiple sources, and transforming raw data into clean, structured information for reporting and analytics. I built this project to strengthen my SQL, data engineering, and data warehousing skills.

## 📦 Technologies

- `Microsoft SQL Server`
- `SQL`
- `ETL (Extract, Transform, Load)`
- `Data Warehousing`
- `Medallion Architecture`
- `Git` and `GitHub`

## 🦄 Features

Here's what you can do with this project:

- **Data Integration**: Load data from multiple source files into a centralized data warehouse.
- **Bronze Layer**: Store raw data from source systems with minimal changes.
- **Silver Layer**: Clean, standardize, and transform data to improve its quality.
- **Gold Layer**: Organize business-ready data for reporting and analytical queries.
- **ETL Pipelines**: Extract, transform, and load data through structured SQL scripts.
- **Data Cleaning**: Handle data inconsistencies and prepare reliable datasets for analysis.
- **Data Modeling**: Create fact and dimension tables to support analytical queries.
- **SQL Analytics**: Write queries to analyze sales performance, customer behavior, and product performance.

## 👩🏽‍🍳 The Process

I started by designing the data warehouse architecture and organizing the project into Bronze, Silver, and Gold layers.

Next, I created the database schemas and tables required to store the data at each stage. I then loaded raw data from CSV files into the Bronze layer using SQL Server.

After loading the data, I developed SQL scripts to clean, standardize, and transform it in the Silver layer. This helped improve data consistency and prepare the data for further analysis.

I then built the Gold layer by creating fact and dimension tables. This structure made it easier to analyze business data and perform reporting tasks.

Finally, I wrote analytical SQL queries to explore sales trends, customer behavior, and product performance. I also organized the SQL scripts and project documentation in GitHub to make the project easier to understand and maintain.
